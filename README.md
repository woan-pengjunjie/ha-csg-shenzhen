用于 Home Assistant 的社区组件，版本 **1.3.3b2**。本仓库供自用验证；不是南方电网官方服务，也不是上游正式发布。

## 变更

- 使用深圳电量日历和账单接口。
- 删除深圳固定阶梯边界、固定电价推算及三个阶梯估算实体。
- 昨日用电按准确日期匹配，支持跨月和跨年，缺失不以最近日期替代。
- 缺失或非法用量、金额保持不可用；明确的真实零值保留。
- 账单仅接受唯一且月份明确匹配的记录，不取列表第一项。
- 深圳上月用量和费用优先从同一户号已取得的年度月明细中，按显式年月唯一匹配；跨年时读取去年明细，缺失字段保持未知。原账单接口仅作无匹配明细时的严格后备，日历查询保留，没有增加外部请求。
- 累计费用传感器使用 HA 2026.10 要求的 `total` 统计元数据；这不提供历史统计回填。
- 登录流程、官方请求域名和其他地区更新分支保持原样；没有增加运行依赖。

## 当前限制

**1.3.3b1 已在 Home Assistant 2026.10.1 完成微信扫码登录，并读取深圳日历用电、本月累计及年度月明细。1.3.3b2 使用同一账号的年度月明细按明确年月填充上月字段。** 直接月账单接口解析仍未通过核验；这些结果不代表其他地区、其他账号或全部接口均可用。

本版本通过 38 项离线测试（原 26 项及新增 12 项），覆盖严格月份、跨年、跨户隔离、重复/缺失/零值/部分字段和年度任务完成顺序。测试仅用合成数据与模拟 I/O，未启动 HA、未登录或请求南网；未加入诊断日志。

年度月明细只接受 `month` 中明确的 YYYYMM 或 YYYY-MM，并要求唯一匹配请求年月；缺项、错月或重复条目不会被猜测选取。直接账单后备筛选仍只接受条目显式 yearMonth（YYYYMM 或 YYYY-MM），该返回字段假设尚待验证。日历仅接受完整日期 YYYY-MM-DD、YYYY/MM/DD 或 YYYYMMDD。

数据是供电局日/月数据，默认每四小时查询，可能延迟。不是实时功率读数；当前月未出账时费用仍保持未知，不由用量估算。上游仍只使用每户第一个计量点，多计量点可能统计不全。会话失效需重新登录。

本版本先用于核对电量、账单和余额。没有历史统计回填，暂勿直接用于 Energy 长期累计统计、扣费或设备控制。不要通过电价乘用量补造账单金额。

## 安装

在 HACS 的自定义仓库中添加本仓库，类别选“集成”，下载默认分支后重启 HA。随后在设备与服务中添加 “China Southern Power Grid Statistics - Shenzhen Experimental”。

与其他 china_southern_power_grid_stat 组件使用同一 domain，不能并行安装。升级或替换前应备份现有配置；从其他仓库更新可能覆盖本修复。

由使用者在本地扫码或短信登录。手机号、登录令牌、绑定户号及相关账户信息会由组件保存在本机 HA，用于查询南网官方服务。公开仓库不需要任何个人账号数据；请勿上传令牌、户号、地址或完整调试日志。
